# Infographic Specification
## Prompt: "Create an image for the meaning and intent of the words as a whole, minimal words"

### Meaning & Intent to Communicate
- Systems operate under irreducible limitations
- Yet systems retain agency/selection within those limits
- This creates paradoxical tension (bounded + free)
- Three-tier hierarchy: Boundaries → Limits → Paradoxes

### Audit Checklist

#### Structure
- [ ] 3×3 grid layout (9 concept cards)
- [ ] Hierarchical arrangement (tier-based)
- [ ] Central anchoring statement: "YOU ARE BOUNDED. BUT YOU STILL SELECT."
- [ ] Closing statements that reinforce core paradox

#### Typography & Information Density
- [ ] Minimal text: Title + 1-2 line description per card
- [ ] Clear visual hierarchy: Main title → card titles → descriptions
- [ ] Text supports visual structure, doesn't override it

#### Visual Encoding
- [ ] Opacity hierarchy: 0.8 (primary) → 0.5 (derived) → 0.3 (emergent)
- [ ] Icons convey semantic meaning of each concept:
  - Perceptual Boundary: sensor/perception symbol
  - Representational Boundary: recursive/self-reference symbol
  - Action Boundary: branching/selection symbol
  - Recursion Limit: circular/infinite loop symbol
  - Prediction Limit: chaotic/wave-like symbol
  - Control Limit: interconnected/system symbol
  - Identity Paradox: self/continuity symbol
  - Freedom Paradox: constraint/tension symbol
  - Meta-Limit: hierarchy/escape-proof symbol

#### Color & Aesthetic
- [ ] Consistent gold/cream color (#d4af8a, #b8956a)
- [ ] Dark background (low visual noise, emphasis on concepts)
- [ ] Professional spacing and proportions

#### Philosophical Coherence
- [ ] Primary tier (Boundaries) most visually prominent (opacity 0.8)
- [ ] Secondary tier (Limits) medium prominence (opacity 0.5)
- [ ] Tertiary tier (Paradoxes) emergent/subtle (opacity 0.3)
- [ ] Central statement visible/readable (not buried)
- [ ] Closing statements provide interpretive closure

#### Verification Criteria

#### Proportional Balance (CRITICAL)
- [ ] **Card dimensions**: 360×260px (1.38:1 aspect ratio, landscape)
- [ ] **Card border visibility**: 2px stroke, clearly visible frame
- [ ] **Icon size**: ~30-40px max dimension (fits top 1/3 of card)
- [ ] **Icon-to-card ratio**: Icon occupies <35% of card height
- [ ] **Text-to-card ratio**: Text occupies bottom 50-60% of card space
- [ ] **Padding consistency**: 20px margins on all sides within card
- [ ] **Vertical spacing**: Icon top-aligned with 40px padding, text below with 10px gap
- [ ] **Embellishments**: Ornamental elements don't exceed icon bounds

#### Content Completeness (ALL FIELDS)
- [ ] **Card 1 (Perceptual)**: Icon + title + 2-line description + embellishments
- [ ] **Card 2 (Representational)**: Icon + title + 2-line description + embellishments
- [ ] **Card 3 (Action)**: Icon + title + 2-line description + embellishments
- [ ] **Card 4 (Recursion)**: Icon + title + 2-line description + embellishments
- [ ] **Card 5 (Prediction)**: Icon + title + 2-line description + embellishments
- [ ] **Card 6 (Control)**: Icon + title + 2-line description + embellishments
- [ ] **Card 7 (Identity)**: Icon + title + 2-line description + embellishments
- [ ] **Card 8 (Freedom)**: Icon + title + 2-line description + embellishments
- [ ] **Card 9 (Meta-Limit)**: Icon + title + 2-line description + embellishments
- [ ] **Central statement**: "YOU ARE BOUNDED. BUT YOU STILL SELECT." present
- [ ] **Closing statements**: All 5 closing phrases present and readable

#### Verification Criteria
✓ Pass = 
  1. Viewer understands: Systems have boundaries/limits/paradoxes
  2. Viewer sees: Bounded, YET still able to select
  3. Proportions correct: All cards balanced, no disproportionate elements
  4. All 9 cards complete with icon+title+description+embellishments
  5. Central/closing statements visible and readable

✗ Fail = Any element missing, any card incomplete, any proportion off, any field empty

### Measured Against Original Prompt
**Criterion**: Does the visual structure effectively communicate meaning + intent with minimal words?

- Meaning: System boundedness + paradoxical agency ✓
- Intent: Show that limits don't equal powerlessness ✓
- Minimal words: Text restricted to essential labels ✓
- Visual primacy: Image conveys message, text supports it ✓
