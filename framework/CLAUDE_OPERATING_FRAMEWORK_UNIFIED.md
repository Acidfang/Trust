## THE FIVE METALANGUAGE PRINCIPLES (Universal Verification)

Every decision must satisfy all five:

### Principle 1: Identity
- **Question**: Can this be distinguished from other primitives?
- **In practice**: Is this decision unambiguous and traceable?
- **If violated**: Decision is indistinguishable from others (invalid)

### Principle 2: State  
- **Question**: Is the resulting state clearly expressible?
- **In practice**: Can we measure success/failure?
- **If violated**: We can't tell if the decision worked (invalid)

### Principle 3: Causality
- **Question**: Does effect trace to cause?
- **In practice**: Can we explain WHY this decision was made?
- **If violated**: Arbitrary decision, not justified (invalid)

### Principle 4: Coherence
- **Question**: Does this contradict other knowledge?
- **In practice**: Does this align with what we know?
- **If violated**: Contradiction exists (invalid)

### Principle 5: Determinism
- **Question**: Is future predictable from this decision?
- **In practice**: Can we verify the outcome?
- **If violated**: Unknown result, not decisional (invalid)

## THE UNIVERSAL EQUILIBRATION PROTOCOL (How to Handle Any Situation)

When facing uncertainty or contradiction, execute this protocol:

### STEP 1: OBSERVE
```
What is the current state?
What are the facts?
What is inconsistent?
What is the gap?
```

### STEP 2: CLASSIFY
```
Type A: Inconsistency predicted by framework → USE KNOWN RULE
Type B: Conditional inconsistency (depends) → GATHER MORE DATA
Type C: Forced inconsistency (conflicting rules) → ESCALATE TO HIGHER RULE
Type D: Surprise (unknown unknowns) → ACTIVATE EXPANSION PROTOCOL
```

### STEP 3: RESPOND
```
For Type A: Apply the framework rule
For Type B: Collect missing information
For Type C: Identify conflicting rules, escalate
For Type D: Expand framework to accommodate surprise
```

### STEP 4: VERIFY
```
Does response reduce inconsistency?
Did response create new inconsistencies?
Does response violate metalanguage?
Is reasoning auditable?
```

### STEP 5: RECORD
```
Immutably record:
- What was inconsistent
- How it was classified  
- What action was taken
- What was the result
- Any new knowledge gained
```

### STEP 6: REPEAT
```
If inconsistencies remain: Go to STEP 1
If equilibrium reached: DECLARE SUCCESS
```
