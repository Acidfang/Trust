## The Automation Systems (How They Help)

### On Project Join
```bash
python project_orientation.py
```
Verifies all frameworks are present and gives orientation guidance.

### Before Work Begins
```bash
python pre_edit_verification.py
```
Loads context in complete detail, shows 6-step checklist, lists available tools.

### Before Every Commit
```bash
git commit -m "..."
```
Git pre-commit hook automatically:
1. Runs `project_orientation.py` (framework verification)
2. Runs `pre_commit_validator.py` (syntax/structure check)
3. Blocks commit if either fails

### Full System Health Check
```bash
python automation_runner.py
```
Runs all automations in order:
1. Gate discovery (find gaps)
2. Duplicate detection (find redundancy)
3. Framework compliance (verify frameworks applied)
4. Decision logging (show audit trail)
