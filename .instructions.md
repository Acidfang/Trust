```

Script executes successfully → Output is WRONG

Not just: "Did it run without errors?"
```

**Applied to every domain, every tier, every compute.**

## Project-Specific Critical Rules

### 4. Scoping (Learned Hard Way - Session 18)

**STRICT ISOLATION**: Each domain/framework/directory must access ONLY its own scope.

```python
WRONG:  for item in PARENT_DIR.rglob('*')     # Recursive, crosses boundaries
        files = global_discovery()             # Gets wrong files

CORRECT: for item in single_dir.iterdir()     # Only direct children
         if item.is_file(): process(item)     # Explicit checks
```

**Rules**:
- Use `Path.iterdir()` NOT `glob()` or `rglob()`
- Check `is_dir()` or `is_file()` explicitly
- Skip hidden files (`startswith('_')` or `'.'`)
- No cross-contamination of metadata

**Example**: cosmology-reversal should list only files IN cosmology-reversal/, not universal-physics files

### 5. Verification Strategy

**DO NOT JUST CHECK EXECUTION. VALIDATE OUTPUT CORRECTNESS.**

```python
WRONG:
  script.run()
  if no_exception: print("Success")

CORRECT:
  result = script.run()
  verify_input_valid()
  verify_output_format()
  verify_relative_paths_work()
  verify_links_are_correct()
  verify_no_cross_contamination()
  round_trip_verify(write + read == original)
```

**Applied to navigation script (Commit bb7be17)**:
- Tier 1: Validate each framework has README
- Tier 2: Extract metadata with strict scoping
- Tier 3: Generate YAML/Markdown with proper escaping
- Tier 4: Verify files written correctly, can be read back

---

### 6. Encoding & Portability

**ALWAYS be explicit about encoding. AVOID non-ASCII characters in print/output.**

```python
WRONG:  print(f"Generated {emoji_char} navigation")  # Fails on Windows CP1252

CORRECT: print(f"Generated navigation")              # ASCII only
         file.write_text(content, encoding='utf-8')  # Explicit UTF-8
         content = file.read_text(encoding='utf-8')  # Explicit UTF-8
```

**Rules**:
- All file I/O: explicit `encoding='utf-8'`
- All print statements: ASCII only (no emoji)
- YAML/JSON: Quote string values
- Escape special chars: `:` → `\:`, `"` → `\"`

## Quick Reference: UFM Applied to Common Tasks

### Adding a Feature
1. **Think first**: Map out all states/transitions
2. **Verify while thinking**: Are all paths covered? No contradictions?
3. **Design I/O**: What files in? What files out?
4. **Verify output format**: Will it be valid?
5. **Code**: Implementation is trivial if thinking was complete
6. **Verify correctness**: Does output match specification?
7. **Document UFM tiers**: Show what checked at each level

### Debugging
1. First: Is execution actually successful or does output just look correct?
2. Check Tier 1: Is input valid?
3. Check Tier 2: Is computation giving correct intermediate results?
4. Check Tier 3: Is output in correct format?
5. Check Tier 4: Is verification logic itself correct?
6. Not: "Let me trace through the code" (do this last)

### Automation
1. Define all four tiers BEFORE writing script
2. Input validation: What makes a file/directory valid?
3. Scoping: Where are boundaries? Use iterdir(), not rglob()
4. Output verification: Generate, then round-trip read to verify
5. Encode properly: UTF-8 everywhere, no emoji in print
