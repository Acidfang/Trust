## 📖 View the Wiki Locally

### Option 1: Simple Python HTTP Server (Fastest)
The wiki markdown files are readable directly in VS Code or any text editor.
Files are located in: `c:\Determined\wiki\docs\`

### Option 2: Jekyll (Professional Local Server)
Requires Ruby and Jekyll installation:

```powershell
# Install Ruby from https://rubyinstaller.org/ (with DevKit)
# Then install Jekyll:
gem install jekyll bundler

# Navigate to wiki directory
cd c:\Determined\wiki

# Install dependencies
bundle install

# Serve locally
bundle exec jekyll serve
# Then visit: http://localhost:4000
```

### Option 3: GitHub Pages (Recommended)
Push to GitHub and enable GitHub Pages on the repository. The wiki will be auto-deployed.
