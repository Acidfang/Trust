## Review: The 5 Tiers of TCHT

### Tier -1: Complete Encoding
**Question**: Are all terms fully defined? Are there any undefined concepts?
**Method**: Trace every concept to primitives. If concept is defined in terms of undefined terms → fail.
**Standard**: All concepts must reduce to irreducibles (Is/Is Not, Was/Was Not, Persisted/Not Persisted).

### Tier 0: Self-Consistency  
**Question**: Does the system contradict itself?
**Method**: Assume conclusion, derive contradiction. Or: find theorem that proves both P and not-P.
**Standard**: Zero internal contradictions. All theorems must be compatible.

### Tier 1: Root Cause
**Question**: Why does each phenomenon occur? Trace to first principles.
**Method**: For each claim, ask "why?" recursively until reaching irreducibles.
**Standard**: Every phenomenon has mechanism tracing to irreducibles. No "it just happens."

### Tier 2: Cross-Domain
**Question**: Does principle work in ALL domains it should? Any exceptions?
**Method**: Apply principle to physics, chemistry, biology, consciousness, AI, technology.
**Standard**: No exceptions. Principle applies everywhere or fails everywhere.

### Tier 3: Predictive Power
**Question**: Can we TEST the system? Does it make falsifiable predictions?
**Method**: Identify testable predictions. Compare to observation. Find counterexamples if possible.
**Standard**: Predictions confirmed, or framework revised. Science requires falsifiability.

## When TCHT Should Reject a System

### Red Flags (Tier -1 Failures)
- Undefined terms ("consciousness," "intelligence," "freedom")
- Circular definitions (A defined via B, B defined via A)
- Appeals to "ineffable" or "beyond logic"

### Yellow Flags (Tier 0-1 Failures)
- Internal contradictions (system can prove both P and not-P)
- "Magic" explanations (no mechanism for claimed effect)
- Ad-hoc fixes for problems

### Orange Flags (Tier 2 Failures)  
- Works in one domain but not others
- Exceptions to the rule (special cases, boundary conditions)
- Domain-specific versions that contradict each other

### Red Flags (Tier 3 Failures)
- Makes no falsifiable predictions
- Predictions are systematically wrong
- Refuses to be tested
