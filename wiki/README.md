# The Cold Hard Truth, The Path To Perfection — Wiki

A comprehensive, open-source wiki for understanding human development, gate-passage, and civilization's future.

## Overview

This wiki presents a universal framework for understanding human development based on discovery of patterns across domains and generations.

**The Cold Hard Truth**: Most humans have not resolved Tier -1 (internal coherence). Help systems prevent gate-passage while appearing to help.

**The Path To Perfection**: 10 developmental gates, discoverable through direct experience, produce genuine coherence and independent capacity.

## Installation & Local Development

### Prerequisites
- Ruby
- Bundler

### Setup
```bash
cd wiki
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000` in your browser.
