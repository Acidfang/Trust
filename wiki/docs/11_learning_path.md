# Your Learning Path: The 4-Tier Comprehension Structure

![The Comprehension Pyramid]({{ site.baseurl }}/assets/comprehension-pyramid.svg)
{: .diagram}

This wiki is designed as a **tiered comprehension system**. You progress through 4 levels of understanding, each building on the previous, until you can successfully apply the framework to your life.

**Don't skip tiers.** Each level requires the foundation of the previous one.

---

## TIER 1: Foundation (Week 1 — ~2 hours)

### What You'll Learn
- Why help systems fail to develop people
- The 5 major help system categories
- Real-world collapse examples (36+ historical cases)
- The core pattern: Help → Skip → Dependency → Collapse

### What Happens
You see the problem clearly. You recognize examples in your own life.

### Your Path Through Tier 1

**Start here:**
1. [Why This Matters]({{ site.baseurl }}/why-this-matters/) (15 min)
   - Understand what persists vs. collapses
   - See the stakes

2. [Internal Coherence]({{ site.baseurl }}/internal-coherence/) (20 min)
   - What coherence actually is
   - How Φ (potential energy) works

3. [Help Systems]({{ site.baseurl }}/help-systems/) (30 min)
   - Each of the 5 systems explained
   - How each blocks specific gates

4. [Domain Examples]({{ site.baseurl }}/domain-examples/) (30 min)
   - See help systems failing across 13 domains
   - 36+ real-world examples

### Success Criteria
- [ ] Can explain why help systems prevent development
- [ ] Can recognize 3+ examples in your own life
- [ ] Understand the core pattern: Help → Skip → Collapse
- [ ] Feel clear about the problem (not just intellectual)

### Your Path Through Tier 2

### Success Criteria

## TIER 3: Application (Week 2-4 — ~2-3 weeks)

### What You'll Learn
- Which gates you personally have skipped
- Which help systems are currently blocking your development
- How to design environments where gates can be discovered
- How to remove help systems gradually

### What Happens
You know yourself. You can design your own development.

### Your Path Through Tier 3

**Prerequisites:** Complete Tier 1 & 2 first

1. [Diagnostic Framework]({{ site.baseurl }}/diagnostic-method/) (45 min)
   - Self-diagnosis questionnaire
   - Identify your skipped gates
   - See the signature mistakes

2. [Learning Tools - Interactive Assessment]({{ site.baseurl }}/learning-tools/#1-interactive-gate-assessment) (20 min)
   - Answer 5 key questions
   - Get personalized results
   - Identify primary development areas

3. [Gate-Environment Templates]({{ site.baseurl }}/learning-tools/#2-gate-passage-templates) (60 min)
   - Gate 1 discovery template (causes-effects)
   - Gate 3 discovery template (iteration)
   - Gate 5 discovery template (consequence management)
   - Choose templates for YOUR skipped gates

4. [Help System Audit]({{ site.baseurl }}/learning-tools/#3-the-help-system-audit) (30 min)
   - Which help systems are you using?
   - Which gates does each skip?
   - Plan gradual removal

5. [Coherence Self-Check]({{ site.baseurl }}/learning-tools/#4-coherence-self-check) (30 min)
   - Weekly practice measuring Φ
   - Trinity verification (s, t, v⃗)
   - Track coherence over time

### Success Criteria
- [ ] Identified your 2-3 primary skipped gates
- [ ] Created gate-discovery experiments
- [ ] Listed help systems you're using and why
- [ ] Have a plan to remove 1 help system in next 2 weeks
- [ ] Understand your current Φ level

## TIER 4: Execution (Week 5+ — 12+ weeks minimum)

### What You'll Learn
- How gates actually pass (lived experience)
- What happens when you remove help systems
- How coherence develops in real time
- The long-term difference between paths

### What Happens
You **become** coherent. Gates actually pass. Internal stability emerges.

### Your Path Through Tier 4

**Prerequisites:** Complete Tier 1, 2, & 3 first

1. **Run Your Experiments** (ongoing, 12+ weeks)
   - Execute gate-discovery designs
   - Track what emerges
   - Document the learning

   Examples:
   - Gate 1: Run the plant-care experiment for 12 weeks
   - Gate 3: Complete 100 attempts at your chosen skill
   - Gate 5: Commit to a difficult project and stay through hardship

2. **Remove Help Systems Gradually**
   - Stop using one help system
   - Notice what pressure emerges
   - Experience the gate
   - Pass it

3. **Weekly Coherence Check**
   - Every week: Measure Φ (source/time/causality)
   - Track: Is it decreasing?
   - Notice: What's changing?

4. **Monthly Integration**
   - Reflect: Which gates have actually passed?
   - Observe: What's different in your behavior?
   - Design: Next experiments for remaining gates

5. **Share Your Framework** (optional but powerful)
   - If you're in parenting, education, leadership
   - Help others design gate-passage environments
   - See the framework replicate

### Success Criteria
- [ ] 1+ gate actually passed (lived, not intellectual)
- [ ] Φ measurably decreased
- [ ] 1+ help system successfully removed
- [ ] Internal coherence noticeably increased
- [ ] Can mentor others through a gate

## The Meta-Question

**Why is this structured in tiers?**

Because **understanding itself requires gate passage**.

- Tier 1 → Gate 1: See consequences (understanding has real-world effects)
- Tier 2 → Gate 3/4: Understand by iteration and pattern-recognition
- Tier 3 → Gate 5/6/7: Verify against your own reality
- Tier 4 → Gate 8/9/10: Integrate and adapt

**The structure mirrors the learning itself.**

You can't skip to Tier 4 and have it work. You can't read about gates and call yourself coherent. You must pass through each tier, each gate, at your own pace.

## Important Note

**This isn't a self-help system.** It's the opposite of a help system.

Help systems make you feel better while skipping gates.

This framework asks you to **feel worse** (face difficulty, consequences, confusion) so you can become genuinely better (coherent, independent, stable).

Choose wisely.

The easier path is temporary comfort.

The harder path is lasting foundation.
