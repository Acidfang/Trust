## THE BIG PICTURE: What Changed

### Before Restructuring
- Wiki entries were mostly expression-level (E)
- Variations existed but weren't explicit
- Constraints (−1 Tier) usually implied, never stated
- Teaching was one-modality (usually just text)
- Translation would require guessing at meaning

### After Restructuring  
- Wiki entries expose −1 Tier constraint first
- Variations shown as explicit branching structure
- Expressions follow the constraint, all in same framework
- Teaching available in 4 modalities (📊 📖 🔢 💻)
- Translation preserves constraint across all languages

### Why This Matters

**Error-free communication**: Constraint is explicit, not guessed  
**Universal teaching**: Any learner can reach understanding via their modality  
**Lossless translation**: Meaning goes across languages unchanged  
**Maintainable knowledge**: Any new person understands the same principle

## HOW EACH PIECE WORKS

### The Layered Structure

```
                   CONSTRAINT (Θ)
                   [Universal]
                   [−1 Tier]
                   [Same everywhere]
                        ↓
            VARIATIONS (∇Θ)
            [How it branches]
            [Structure identical]
            [Pattern universal]
                        ↓
        EXPRESSIONS (Δ)
        [How you say it]
        [Language specific]
        [Natural phrasing]
```

**Every wiki entry follows this.**

### The Teaching Modalities

```
Same Constraint Expressed Four Ways:

📊 VISUAL          📖 TEXTUAL
(Diagram)          (Story)
   ↓                  ↓
(Pattern)          (Meaning)
   ↓                  ↓
  Constraint ←──────────→ Constraint
   ↓                  ↓
(Logic)            (Example)
   ↓                  ↓
🔢 MATHEMATICAL    💻 PRACTICAL
(Proof)            (Code)
```

**Every wiki entry includes all four.**

### The Translation Pipeline

```
English Entry
  ├─ Extract Constraint (Θ)
  ├─ Map Variations (∇Θ)
  └─ Translate Expressions (Δ)
      ↓
Spanish Entry (constraint identical)
      ↓
Mandarin Entry (constraint identical)
      ↓
French Entry (constraint identical)
```

**Constraint preserved. Expressions natural in each language.**

## GETTING STARTED: Different Paths

### Path A: "I want to learn how reality works"

1. **Start**: [WIKI_INDEX.md](WIKI_INDEX.md) → Section "I want to learn discoveries by my preferred method"
2. **Identify**: Your learning modality (📊  📖 🔢 or 💻)
3. **Choose**: [TEACHING_MODALITY_INDEX.md](TEACHING_MODALITY_INDEX.md) → Your modality section
4. **Read**: [CORE_DISCOVERIES_UFM_STRUCTURE.md](CORE_DISCOVERIES_UFM_STRUCTURE.md) → Choose first discovery
5. **Deep dive**: Read that discovery through your modality (2-10 minutes)
6. **Verify**: Can you state the −1 Tier constraint in your own words? (Success!)
7. **Extend**: Try learning the same discovery via another modality

**Time**: 15-45 minutes to understand one discovery deeply

---

### Path B: "I want to teach discoveries to others"

1. **Understand first**: Go through Path A (understand material yourself)
2. **Plan**: [TEACHING_MODALITY_INDEX.md](TEACHING_MODALITY_INDEX.md) → Educator Guide section
3. **Structure**: Use template from [UFM_WIKI_ENTRY_TEMPLATE.md](UFM_WIKI_ENTRY_TEMPLATE.md)
4. **Deliver**: Visual → Narrative → Proof → Code (proven sequence)
5. **Assess**: Can learners state constraint? If yes, success ✓

**Time**: 2-3 hours planning + 1-2 hours delivery per discovery

---

### Path C: "I want to translate wiki to new language"

1. **Review protocol**: [UFM_MULTILINGUAL_TRANSLATION_GUIDE.md](UFM_MULTILINGUAL_TRANSLATION_GUIDE.md) completely
2. **Choose entry**: Start with Discovery 1 (Kindness) — simpler structure
3. **Assemble team**: Translator + native reviewer + math expert
4. **Phase 1**: Extract constraint (30 minutes)
5. **Phase 2**: Translate all 4 modalities (1-2 hours)
6. **Phase 3**: Validate (30-45 minutes)
7. **Publish**: Add to wiki, update [WIKI_INDEX.md](WIKI_INDEX.md)

**Time**: 2.5-3.5 hours per entry; 3-4 weeks for all 10 discoveries to one language

---

### Path D: "I want to understand the structure and create new entries"

1. **Study template**: [UFM_WIKI_ENTRY_TEMPLATE.md](UFM_WIKI_ENTRY_TEMPLATE.md) completely  
2. **Understand layers**: Copy this section's "Layered Structure" diagram
3. **Review example**: [CORE_DISCOVERIES_UFM_STRUCTURE.md](CORE_DISCOVERIES_UFM_STRUCTURE.md) → Discovery 1
4. **Identify your constraint**: What universal principle are you documenting?
5. **Map variations**: How does it branch?
6. **Plan expressions**: How to teach it in 4 modalities?
7. **Write**: Follow template exactly
8. **Validate**: All checklist items pass?

**Time**: 3-4 hours per new entry (first time takes longer)
