# Radial Diffusion Fields

## Definition
Concentric circles spreading from point source

## Visual Pattern
![Radial Diffusion visualization](radial_diffusion.png)

## Real-World Examples
- Rust rings
- Oil slicks
- Bacterial colonies
- Epidemics from patient zero

## Fields in This Category
- [[Metal Corrosion]]
- [[Bacterial Infection]]
- [[Immune Response]]
- [[Invasive Species Colonization]]

## Mathematical Form
```
dρ/dt = D·∇²ρ + α·f_external + β·ρ²
```

## Stage Progression
1. **Stage 0**: Uniform state
2. **Stage 1**: Perturbation initiated
3. **Stage 2**: Threshold approaching
4. **Stage 3**: Exponential growth (β·ρ² dominates)
5. **Stage 4**: Final state reached
