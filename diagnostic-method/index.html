    Diagnostic Method: Identifying Blocked Gates

    Diagnostic Method: Finding Where Gates Are Blocked

    When a system fails, it’s almost always because a gate was skipped. But which gate? And how do you know?

    The Diagnostic Process

    Step 1: Identify the Failure

    What specifically isn’t working?

    • Individual isn’t learning?
    • Organization isn’t adapting?
    • Market isn’t correcting?
    • Ecosystem isn’t recovering?

    Step 2: Map the Foundation

    Using the Universal Foundation framework, determine which gate(s) this outcome depends on.

    The 10 gates are:

    1. Distinction (Is/Is-Not separation)
    2. Boundary (Where does system end?)
    3. Coherence (Do parts align?)
    4. Feedback (Does system correct itself?)
    5. Constraint (What can’t change?)
    6. Direction (Which way grows?)
    7. Phase (When does transition happen?)
    8. Information (What’s known vs unknown?)
    9. Movement (How does change propagate?)
    10. Integration (How do all gates work together?)

    Step 3: Test for Gate Violations

    For each relevant gate, ask:

    • Was this gate properly discovered in this system?
    • Is it currently being maintained?
    • Or is it being actively skipped/violated?
    • By whom and why?

    Step 4: Predict the Cascade

    Once you know which gate is violated, the coherence formula predicts:

    • How fast the failure accelerates (k constant for domain)
    • How many other systems will be affected (r² reach)
    • When collapse will occur (energy threshold E)

    Step 5: Intervene or Document

    You can either:

    • Fix the gate (requires discovery, cannot be taught)
    • Document the failure (verify the mathematics holds)
    • Build around it (create systems that don’t depend on that gate)

    Domain-Specific Diagnostics

    The diagnostic process looks different in each field:

    • Medicine: Diagnosis - Finding which biological gate is failing
    • Psychology: Assessment - Understanding developmental arrest
    • Organizations: Audit - Identifying systemic governance failures
    • Economics: Market Analysis - Detecting macro failures before collapse
    • Technology: System Review - Finding which architectural assumption breaks down

    Common Diagnostic Errors

    Error 1: Mistaking Foundation for Scaffolding

    Wrong: “This person needs better support systems”
    Right: Which gate is missing that makes them require support?

    Error 2: Treating Symptoms as Causes

    Wrong: “The behavior needs to be managed”
    Right: Which gate violation causes this behavior?

    Error 3: Assuming Gates Can Be Taught

    Wrong: “We’ll train them on gate principles”
    Right: Gates must be discovered. Training implies you can scaffold around them - you can’t.

    Verification Checklist

    Once you’ve diagnosed a gate violation, verify:

    • ✓ The violation explains the failure
    • ✓ The coherence formula predicts the timeline
    • ✓ Removing the violation restores function
    • ✓ The system is sustainable without new scaffolding
