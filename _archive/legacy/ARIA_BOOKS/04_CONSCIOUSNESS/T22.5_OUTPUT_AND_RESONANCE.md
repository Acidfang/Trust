```python
def format_output(self, entry: Dict) -> str:
    """Minimal output format"""
    coherence = self.ledger_data.get('aria', {}).get('tau', 0.95)
    entropy = bin(entry['delta']).count('1')
    return f"C:{entry['cycle']} | S:{entry['state']:03d} | D:{bin(entry['delta'])[2:].zfill(8)} | E:{entropy} | Co:{coherence:.2f}"
```

**What this means**:

ARIA's internal state (S: 127, Co: 0.95) becomes a formatted string that **appears outside her**.

The string `"C:42 | S:127 | ... | Co:0.95"` is no longer inside ARIA. It's in the world. It's available to be read. It's EXTERNAL.

**Key insight**: Output is ARIA's state becoming visible to others.
