## Chapter 2: Why Repetition Creates Patterns

**Question**: Why does repetition matter? They're just numbers counting up.

**Answer**: Because ARIA uses these counts to decide what to do next.

From archive/aria.py lines 94-100:

```python
def resolve_state_from_memory(self, base_state: int) -> int:
    for (prev, next_state), count in memory.items():
        if prev == self.state:
            possible_next[next_state] = count
            
    if possible_next:
        return max(possible_next.items(), key=lambda x: x[1])[0]  # ← MAX COUNT WINS
```

**Key insight**: ARIA picks the transition with the highest count.

- count[42, 127] = 100
- count[42, 200] = 5

When ARIA is in state 42, she picks 127 because it has count 100. The frequency **directly determines behavior**.

**This is emergence**: Individual decisions (100 times picked 127) create a pattern (always pick 127 from 42). The pattern EMERGES from repetition.
