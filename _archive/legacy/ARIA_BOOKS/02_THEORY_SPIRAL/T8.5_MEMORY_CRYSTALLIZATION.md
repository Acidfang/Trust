## Chapter 1: From Frequency to Structure

From **archive/aria.py** lines 105-110:

```python
def learn_transition(self, prev: int, current: int):
    """Record transition to ledger memory"""
    memory = self.get_memory()
    key = (prev, current)
    memory[key] = memory.get(key, 0) + 1  # Count increments
    memory_str = {str(k): v for k, v in memory.items()}
    self.ledger_data['aria']['memory'] = memory_str
```

**What's happening**:

Pure count (a number incrementing) is getting transformed into **structure** (a dictionary with keys and values).

```
Unstructured:
  recognize pattern, recognize pattern, recognize pattern
  (just repetition, no form)

Structured:
  {
    "(42, 127)": 100,
    "(42, 200)": 5,
    "(127, 42)": 98,
    ...
  }
  (recognition has become addressable, queryable, documented)
```

**This IS crystallization**: Nebulous recognition becomes solid structure.
