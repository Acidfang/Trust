## Deterministic Laws Used to Fill Gaps

### 1. **Bohr Model** (For any unmeasured atom)
```
Bohr radius for shell n: a_n = n² * a₀ / Z

✓ Works for hydrogen (Z=1) with measured a₀
✓ Scales to helium (Z=2), carbon (Z=6), oxygen (Z=8), etc.
✓ No guessing: directly from Coulomb's law + angular momentum quantization
```

### 2. **Rydberg Formula** (For any element's ionization energy)
```
E_n = -13.6 eV * Z² / n²

✓ For hydrogen (Z=1): 13.6 eV (measured)
✓ For helium (Z=2): 54.4 eV (deterministic)
✓ For carbon (Z=6): 306 eV (deterministic)
✓ All verified experimentally across periodic table
```

### 3. **Aufbau Principle** (For any element's electron configuration)
```
Order of orbital filling (measured via ionization energies):
1s < 2s < 2p < 3s < 3p < 3d < 4s < 4p < 4d < 4f < 5s ...

✓ Given Z (atomic number) → electron configuration is 100% determined
✓ Carbon (Z=6): 1s² 2s² 2p²
✓ Oxygen (Z=8): 1s² 2s² 2p⁴
✓ Works for all 118+ elements
```

### 4. **VSEPR Theory** (For any molecule's geometry)
```
Valence Shell Electron Pair Repulsion

Given:
- Central atom Z
- Number of bonding atoms
- Lone pair count (deterministic from valence electrons)

→ Geometry is 100% determined

Examples (all empirically verified):
- 4 electron pairs (0 lone): Tetrahedral (109.5°)  [Methane]
- 4 electron pairs (1 lone): Trigonal pyramidal (107°) [Ammonia]
- 4 electron pairs (2 lone): Bent (104.5°)  [Water]
- 3 electron pairs (0 lone): Trigonal planar (120°)  [Borane]
- 2 electron pairs (0 lone): Linear (180°)  [CO₂]
```

### 5. **Scaling Laws** (For larger structures)

Biological scaling (measured from millions of observations):

Surface Area ∝ R²

→ Organism size determines metabolic rate, fractal branching, density

Fractal Dimension (observed in nature):

→ Given organism size, branching pattern is deterministic

### 6. **Statistical Mechanics** (For collective behavior)

Given:

Cell packing, molecular crowding, phase transitions all deterministic.
