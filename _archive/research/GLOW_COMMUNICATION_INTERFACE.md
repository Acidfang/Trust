### Methods Behind the Interface

- `sendGlowMessage()` - Triggered on Enter or Send button click
- `addGlowMessage(text, sender)` - Displays message in history
- `computeThinkingState(query)` - Analyzes query, activates relevant domains
- `generateThinkingResponse()` - Creates visible thinking phases (600ms each)
- `generateResponse()` - Formulates actual response based on patterns

### State Tracking

- `this.glowMessages` - Chat history
- `this.isThinking` - Flag for thinking state visualization
- `this.thinkingDomains` - Which domains are actively engaged
- `fieldActivation` - Per-domain sine wave in compute6DState()
