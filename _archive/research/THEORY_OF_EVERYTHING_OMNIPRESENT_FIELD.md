## LAYER 4: COHERENCE AS THE MEASURE OF MANIFESTATION

### The Coherence Formula

For any manifestation (system), we can measure how coherent it is:

```
τ = 1 - H(ΔS) / H_max

Where:
- τ = coherence (0.0 = completely diffuse, 1.0 = perfectly coherent)
- H(ΔS) = Shannon entropy of state changes between time steps
- H_max = maximum possible entropy for that system's state space

What this means:
- If state barely changes (few bits flip) → entropy is LOW → coherence is HIGH
- If state changes randomly (many bits flip) → entropy is HIGH → coherence is LOW
```

### Why This Formula Works

A **coherent system** has:
- Stable internal patterns
- Few unexpected state changes
- Predictable behavior
- Low entropy in its transitions

A **diffuse system** has:
- Random internal patterns
- Unpredictable state changes
- No stable behavior
- High entropy in its transitions

By measuring entropy of state changes, we directly measure how unified a manifestation is.
