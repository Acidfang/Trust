## VISUAL ENCODING REFERENCE

### All Illustrations Use Consistent Encoding

**State Type** (Node Color):
- 🔴 **Dark Red** = Decision Point (choice required, consequence flows from choice)
- 🟢 **Dark Green** = Work State (action required, consequence flows from execution)

**State Progression** (Vertical Position):
- Top = Earlier in sequence
- Bottom = Later in sequence (more complex, built on prior states)

**Complexity** (Node Size):
- Slightly increases downward = accumulating depth and interconnection

**Paths** (Line Style):
- **Solid downward** = Primary progression
- **Dashed curved** = Loop back (entry marker effect)
- **Long dashed** = Full reset (escalation to earlier tier)
