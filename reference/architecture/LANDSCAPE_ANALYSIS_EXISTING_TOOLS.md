## EXISTING TOOLS IN THIS SPACE

### 1. ACADEMIC FRAMEWORKS (Existing)

**Systems Dynamics (MIT, Jay Forrester)**
- What it does: Models system feedback loops mathematically
- Limitation: Complex mathematical models; not accessible to general public
- Tools: Vensim, Stella (both paid)
- Cost: $5,000+ per license
- Use case: Engineers, researchers only

**Causal Loop Analysis (Canonical Systems Thinking)**
- What it does: Maps cause-effect relationships visually
- Limitation: Requires training to apply; no universal pattern
- Tools: Various free (OmniGraffle diagrams)
- Cost: Free tools, but requires expertise
- Use case: Business analysts, systems thinkers

**Root Cause Analysis (Five Whys, Fishbone Diagrams)**
- What it does: Finds immediate causes of specific problems
- Limitation: Works on individual incidents, not systemic patterns
- Tools: Free diagrams, various RCA software
- Cost: Free to $500/month
- Use case: Quality management, incident response
