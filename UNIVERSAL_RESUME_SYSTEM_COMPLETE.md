## CRITICAL SUCCESS FACTORS

1. **Update EXECUTION LOG after every work session**
   - Don't skip this
   - Format: [Date] [AI] [Task] [Status] [Next]
   - Next AI depends on this being current

2. **Always leave a "Next AI should..." note**
   - Be specific
   - Example: "Next AI should submit to Zenodo using Section 9 of PROJECT_STATE.md"
   - Don't assume next AI will figure it out

3. **Keep CURRENT STATE accurate**
   - Update when status changes
   - Update when files are created/modified
   - Update when tasks complete/block

4. **Never hide problems**
   - Document issues in PROJECT_STATE.md Section 8
   - Mark tasks with 🔄 [RESUME AT: X] if incomplete
   - Mark tasks with ⚠ [BLOCKED: reason] if stuck

5. **Reference the documents in your code**
   - Comments like: "See PROJECT_STATE.md Section 4 for build system"
   - Links like: "Read CHECKPOINT_QUICK_START.md for quick resume"
   - Don't duplicate information
