## STRUCTURE TEMPLATE FOR EACH PAGE

### Required Frontmatter
```yaml
---
layout: default
title: "Clear, Descriptive Title"
permalink: /path/to/page/
description: "One-sentence summary"
status: published/draft/internal
difficulty: beginner/intermediate/advanced
reading_time: "X minutes"
target_audience: "Who should read this?"
last_updated: "2026-06-28"
version: "1.0"
---
```

### Recommended Sections
1. **Overview** - What is this about?
2. **Why This Matters** - Why should you care?
3. **Core Concepts** - What are the key ideas?
4. **Practical Application** - How do you use this?
5. **Examples** - Real-world demonstrations
6. **Related Pages** - Other relevant content
7. **Next Steps** - Where to go from here
