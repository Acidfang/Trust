7. **Constraint Distribution Trade-offs**: Central vs distributed tradeoffs
8. **Constraint Coupling**: Constraints interact; can't change independently
9. **Scale-Dependent Constraints**: Constraint types change with scale
10. **Constraint Precision vs Cost**: Precision has cost; optimize for necessary precision
11. **Constraint Efficiency Trade**: Constraints can increase efficiency via automation

13. **Measurement/Observation as Constraint**: Observing constrains the observed
14. **Temporal Constraint Positioning**: Constraints can be pre-positioned
15. **Constraint Type Determines Outcome**: Problem type determines solution
16. **Constraint Stacking/Redundancy**: Multiple independent constraints provide safety
17. **Constraint Landscape Topology**: System structure affects solvability
18. **Inverse Constraint**: Constraining can increase output

```

Our approach:
```

- Our approach: "Tired? Map constraints (thyroid, sleep, stress, fitness) → find which is binding → treat that"
