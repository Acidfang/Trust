## ⚠️ TROUBLESHOOTING

### Port Already In Use
```
ERROR: Port 5005 already in use
```

**Solution:**
```powershell
# Find process using port
Get-NetTCPConnection -LocalPort 5005

# Kill it
Stop-Process -Id <PID> -Force

# Try startup again
python startup_unified.py
```

### Module Not Found
```
ERROR: ModuleNotFoundError: No module named 'flask'
```

**Solution:**
```powershell
# Verify virtual environment is activated
# Should see (.venv) in terminal prompt

# If not activated:
& ..\..\..\venv\Scripts\Activate.ps1

# Reinstall dependencies:
```
