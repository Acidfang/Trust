## 6.2: LEARNING AND UTILITY MODIFICATION


**Scenario 2: Vicarious Learning**

```

```

**Scenario 3: Reflective Learning**

```
Election E₁: Chose action A based on U_old
Result: Outcome was bad (U_actual < U_predicted)

Reflection:
  "Why did I make wrong prediction?"
  "What was wrong with my utility function?"
  "How should I change it?"

Update: U_new = Modified(U_old, given observation)

Why this works:
  Reading timeline reveals mistakes.
  Mistakes point to wrong utilities.
  Correction improves future choices.
```

### Utility as Probability

**Advanced Model:**

Instead of single utility value, track probability distribution:

```
Old: U(action) = +50 (certain)

After learning:
P(good | action) = 0.7
P(bad | action) = 0.3

Expected utility: E[U] = 0.7 × (+100) + 0.3 × (-50) = +55

This captures uncertainty while still guiding choices.
```

**Bayesian Update:**

With each election outcome, update probability:

```
Prior: P(good | action) = 0.5 (no information)

Observe: action leads to good outcome
Likelihood: P(outcome | good) = high

Posterior: P(good | action) = updated (moves toward 0.7)

Next election uses updated probability.
```

This is how learning becomes automatic.
