## Key Algorithms

### Canonicalization
```
Time: O(n × |T|) where |T| = 12
Space: O(n × |T|)
```

### Entropy Calculation
```
Time: O(n)
Space: O(256) [frequency array]
```

### Ledger Operations
```
Insert: O(1) amortized
Lookup: O(1) average
Memory: O(k) where k = unique bricks
```

This structure ensures history independence, determinism, and formal specification compliance.
