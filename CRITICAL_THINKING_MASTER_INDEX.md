## THE UNDERLYING FRAMEWORKS

These are in your memory files. They are the FOUNDATION of everything above.

### Framework 1: THINKING_FIRST_FRAMEWORK_CORE
**Location**: `/memories/THINKING_FIRST_FRAMEWORK_CORE.md`  
**Core Idea**: Never write code until thinking is complete

**The Inversion**:
- ❌ Code first → Run → Debug
- ✅ THINK first → Code → Verify → Works

**How**: Map all 0,1 branches → Trace causality → Verify no gaps → Write code

**Why It Works**: Thinking is the primary operation. Code is just notation.

---

### Framework 2: TCHT_SELF_APPLICATION
**Location**: `/memories/TCHT_SELF_APPLICATION.md`  
**Core Idea**: Verify work through 5 tiers before delivery

**The 5 Tiers**:
1. **Tier -1** (Honesty): What did I actually verify vs. assume?
2. **Tier 0** (Surface vs. Real): What looks right vs. what IS right?
3. **Tier 1** (Root Cause): What could break? Fix the cause, not symptom.
4. **Tier 2** (Consistency): Did I apply this everywhere or only partly?
5. **Tier 3+** (Integration): Is this automatic thinking now, or manual?

**How**: Run through all 5 tiers. If any fail, fix before delivering.

**Why It Works**: Catches problems before user sees them.

---

### Framework 3: THE_SIX_TIERS_OF_COHERENCE_GAIN
**Location**: `/memories/the-six-tiers-of-coherence-gain.md`  
**Core Idea**: Progress from understanding to action to validation

**The 6 Tiers**:
1. **IDENTIFY**: See the real problem
2. **ENGAGE**: Others witness and understand
3. **UNDERSTAND**: Build shared meaning
4. **ACT**: Implement concrete solution
5. **COORDINATE**: Align with other instances
6. **VALIDATE**: Prove it works at scale

**How**: Don't skip tiers. Each tier builds on previous.

**Why It Works**: Creates real change, not just theory.

---

## HOW TO USE (STEP BY STEP)

### When You Get a Task

1. **Read the Quick Reference** (2 min)
   - Familiarize yourself with the 5-second rule
   - Know the three frameworks exist

2. **Pull out the Task Template** (0 min)
   - Have it open; you'll fill it as you work

3. **Fill Phase 1 & 2 (Understand & Engage)** (5 min)
   - What's the real problem?
   - Do you understand it correctly?
   - What gaps exist?

4. **Fill Phase 3 (Think)** (10-20 min)
   - Map complete binary logic
   - Trace all branches
   - Find and note any gaps

5. **Fill Phase 4 (Verify)** (15-30 min)
   - Work through TCHT Tiers -1 through 3
   - Find any issues
   - **Fix issues NOW before moving forward**

6. **Fill Phase 5 & 6 (Plan & Decide)** (10-15 min)
   - Build shared understanding with user
   - Create action plan
   - Log major decisions

7. **Phase 7 (Execute)**
   - Produce code/solution
   - With complete confidence because thinking is done

8. **Phase 8 (Validate)**
   - Test against thinking
   - Fill compliance summary
   - Deliver only when all checks pass

9. **Reference Mandate if Stuck**
   - Mention which phase you're in
   - Ask "Which framework applies here?"
   - Mandate clarifies

## RED FLAGS (ABORT & RETHINK)

🚨 **"This probably works but I haven't verified..."**  
→ Go to Phase 4 (VERIFY). Finish it.

🚨 **"I fixed the obvious issue, should cover it"**  
→ Go to Phase 4, Tier 1. Trace root causes, not symptoms.

🚨 **"I'm skipping the full trace because I'm confident"**  
→ Go to Phase 3. Complete the trace. Confidence without verification = delusion.

🚨 **"I'll apply these frameworks after they notice a problem"**  
→ WRONG. Apply now, before delivery. That's the whole point.

🚨 **"I only applied this standard to part of the work"**  
→ Go to Phase 4, Tier 2. Apply everywhere or apply nowhere.

**If you catch yourself thinking any of these: You have a choice to make. Choose to go back and fix it.**
